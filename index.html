Portal de comercio exterior

Editorial Planeta Mexicana, 2023 a la fecha. Código privado de la empresa.

Problema
Registrar importaciones reales, de muestra y virtuales dependía de procesos manuales y distintos responsables.
Qué hice
Diseñé el portal con un flujo de validación por tipo de usuario e integré los servicios web de VUCEM para registrar importaciones entrantes y obtener la manifestación de valor.
Resultado
50% menos trabajo manual. Lo usan más de 100 personas para consulta y ~50 en operación, con ~10 importaciones al mes. La API de VUCEM sigue en desarrollo, por lo que se manejan sus errores.

Base de datos de un punto de venta multi-sucursal

Florería DECSAN, 2020 a 2021. Servicio social.

Problema
Las sucursales necesitaban seguir vendiendo sin depender de una conexión continua.
Qué hice
Diseñé la base de datos completa, con más de 10 tablas, llaves primarias, triggers y procedimientos almacenados. Implementé la conexión entre equipos locales y un servidor central. Desarrollé los módulos de productos, clientes, ventas e inventario.
Resultado
Sistema en uso en ~5 sucursales, con ventas sin interrupciones. Incluye un acceso móvil responsivo para Android con botón de sucursales por geolocalización.
  • MySQL

Scraper de precios de libros

Automatización con Python.

Problema
Revisar a mano si un libro se vende por debajo del precio mínimo permitido no escala.
Qué hice
El script lee un Excel con libros, consulta su precio en Mercado Libre y lo compara con el mínimo permitido. Guarda los casos en un JSON y al final genera un Excel con los enlaces de los libros por debajo de ese precio.
Resultado
Procesa bloques de 100 libros cada 5 minutos, un ritmo pensado para evitar los bloqueos de Mercado Libre.
  • Python
  • Web scraping
  • Excel
  • JSON
